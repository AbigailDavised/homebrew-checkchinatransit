# Homebrew Tap for checkchinatransit-cli (checkchinatransit.com)

Official Homebrew tap for **[checkchinatransit.com](https://checkchinatransit.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/checkchinatransit
brew install checkchinatransit-cli
```

## Quick Test

```bash
checkchinatransit-cli --help
```
